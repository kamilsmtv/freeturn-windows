## [0.1.0] — первый выпуск

Десктопный клиент ядра [free-turn-proxy](https://github.com/samosvalishe/free-turn-proxy)
для Windows 10/11 x64: одно самодостаточное приложение вместо командной строки.

### Добавлено

- **Профили серверов**: список, создание, правка, клонирование и удаление;
  у клона свой `client-id`.
- **Обмен настройками**: ссылки `freeturn://` с QR-кодом, подписки `sub.md`
  с обновлением по расписанию, резервные копии, совместимые с Android-клиентом.
- **Режимы работы**: прокси и VPN со встроенным туннелем WireGuard/AmneziaWG —
  отдельный клиент WireGuard не нужен.
- **Управление VPS по SSH** через `install.sh` ядра: установка, запуск и
  остановка, журнал сервера, настройка WireGuard, приглашение гостей ссылкой.
- **Живой журнал ядра** с фильтром по уровню, поиском и выгрузкой в файл.
- **Автообновление ядра** из релизов GitHub: сверка версий, changelog,
  проверка SHA256, атомарная замена и откат на прежнюю сборку.
- **Интеграция с Windows**: значок в трее с состоянием подключения,
  сворачивание в трей, автозапуск, автоподключение, тема по системной.

### Известные ограничения

- Раздельное туннелирование работает по подсетям, а не по приложениям:
  аналога `VpnService` в Windows нет.
- Счётчики трафика доступны только в режиме VPN — в режиме прокси их
  неоткуда взять.
- При аварийном завершении (`taskkill /F`) маршруты ядра снимаются
  при следующем запуске, а не сразу.

Подробности — в [руководстве](docs/guide.md).
